## Windows

Run `Murmur.exe`. To add it to the Start menu: `Murmur.exe --install`

2.3 MB, under 25 MB of memory, under 1% of a core. Not code-signed yet, so on the SmartScreen warning choose **More info**, then **Run anyway**.

Press `?` in the app for the keys.

## Web

[goodly58.github.io/murmur](https://goodly58.github.io/murmur/) installs from the address bar and works offline.
